# Academic Security Research Documentation

## Project Overview

**Project Title**: Multi-Factor Authentication (MFA) Security Analysis and Comparison
**Course**: CSCI 401 - Password Security: Efficacy of MFA
**Research Team**: Michael Janus, Abdelghafour El Bikha, Jennifer Marrero

**Research Objective**: To analyze and compare the effectiveness of various Multi-Factor Authentication (MFA) methods in preventing account compromise attacks. This educational research project demonstrates that basic password-only authentication is inadequate and that even weak passwords become significantly more secure when supplemented with appropriate MFA.

## Problem Statement

In today's digital landscape, accounts are increasingly compromised through credential-based attacks:
- **81% of hacking-related breaches** leverage stolen or weak passwords (Verizon, 2023)
- **78% of users** reuse passwords across multiple platforms (CinchOps, 2025)
- **94% of passwords** exposed in breaches are reused or duplicated
- **49% of security incidents** involving stolen credentials use them as initial access vector

This research addresses a critical knowledge gap in understanding that not all MFA implementations provide equal security benefits, and demonstrates through quantifiable analysis how proper MFA can prevent over 95% of credential-based attacks.

## Research Scope

### Authentication Methods Analysis
The research will evaluate five authentication methods against simulated credential-based attacks:

1. **Password Only** (Baseline control group)
2. **SMS-Based MFA** - One-time codes via text message
3. **TOTP Authenticator App** - Time-based codes from mobile apps (Google Authenticator, Authy)
4. **Security Questions** - Knowledge-based authentication using personal questions
5. **Hardware Security Tokens** - Physical devices like YubiKey or similar

### Attack Simulation
- **Credential Stuffing Attacks**: Automated attempts using breached credential databases
- **Brute Force Attacks**: Systematic password guessing with various attack patterns
- **Phishing Simulations**: Social engineering attempts targeting authentication weaknesses

### Success Metrics
- **Attack Success Rate Reduction**: Target <5% success rate (compared to baseline)
- **Time-to-Breach Measurement**: Extended duration before successful compromise
- **User Experience Impact**: Authentication completion time and user satisfaction

## Vulnerability Assessment Framework

### Authentication Security Analysis

#### MFA Method Vulnerabilities
- **SMS Interception**: SIM swapping, social engineering, carrier vulnerabilities
- **Authenticator App Compromise**: Device theft, malware infection, backup code recovery
- **Security Question Weaknesses**: Information availability, social media research, predictable answers
- **Hardware Token Loss**: Physical device loss, backup unavailability, cost barriers
- **Replay Attacks**: Code capture, time manipulation, synchronization issues

#### Assessment Methodology
- **Static Analysis**: MFA implementation review, configuration analysis, dependency assessment
- **Dynamic Testing**: Penetration testing against MFA bypasses, attack simulation
- **Comparative Analysis**: Success rate measurement, user experience evaluation, cost-benefit analysis
- **Risk Scoring**: Vulnerability assessment per MFA type, threat model validation

## Detection Mechanisms

### 1. Attack Detection Systems

#### Monitoring Tools
- **Web Application Firewall (WAF)**: Request pattern analysis for credential stuffing
- **Intrusion Detection System (IDS)**: Network traffic analysis for brute force patterns
- **Security Information and Event Management (SIEM)**: Failed authentication attempt correlation
- **Application Performance Monitoring (APM)**: Authentication flow analysis, anomaly detection

#### Detection Algorithms
- **Statistical Analysis**: Baseline establishment for normal authentication patterns, deviation detection
- **Machine Learning**: Behavioral analysis for authentication patterns, anomaly detection
- **Rate-Based Analysis**: Threshold monitoring for repeated failed attempts, velocity checking
- **Geographic Analysis**: Location-based anomaly detection, impossible travel detection
- **Device Fingerprinting**: Browser and device consistency verification, new device alerting

### 2. Authentication Integrity Monitoring

#### Session Management
- **Concurrent Session Detection**: Multiple active sessions from same account
- **Session Hijacking Prevention**: Token validation, session binding, secure logout
- **Authentication Flow Analysis**: Complete authentication path tracking, abandonment detection
- **Privilege Escalation Monitoring**: Administrative access attempt detection, role violation alerts

## Prevention Mechanisms

### 1. MFA Implementation Controls

#### SMS-Based MFA Security
- **Carrier Verification**: Legitimate carrier validation, SIM swap detection
- **Rate Limiting**: Code request frequency limits, attempt throttling
- **Code Lifespan**: Short expiration windows, single-use enforcement
- **Backup Methods**: Alternative delivery channels, voice call verification
- **Device Binding**: Known device association, new device verification requirements

#### Authenticator App Security
- **Device Security**: App-based device verification, jailbreak detection
- **Backup Codes**: Secure recovery options, one-time backup generation
- **Secure Enrollment**: QR code verification, manual code entry validation
- **Time Synchronization**: NTP synchronization, time drift detection, replay prevention

#### Security Question Controls
- **Question Complexity**: Non-public information requirements, answer complexity guidelines
- **Rate Limiting**: Attempt frequency limits, lockout mechanisms
- **Answer Obfuscation**: Secure hashing, incorrect answer delay masking
- **History Tracking**: Previous answer logging, pattern analysis, change detection

#### Hardware Token Security
- **Physical Security**: PIN protection, tamper evidence, secure element design
- **Backup Methods**: Recovery codes, secondary authentication options
- **Device Registration**: Secure enrollment process, verification procedures
- **Revocation**: Secure token invalidation, remote wiping capabilities

### 2. Comprehensive Defense Strategies

#### Multi-Layer Authentication
- **Adaptive Authentication**: Risk-based MFA requirements, contextual security
- **Defense in Depth**: Multiple independent authentication factors, system-level protection
- **Zero Trust Architecture**: Principle of least privilege, secure channel design
- **Continuous Verification**: Ongoing authentication validation, session integrity checks

#### Attack Prevention
- **Credential Stuffing Defense**: Unique credential detection, account takeover prevention
- **Brute Force Mitigation**: Exponential backoff, CAPTCHA integration, IP blacklisting
- **Social Engineering Resistance**: Phishing detection, user education, secure communication practices

#### User Education
- **Security Awareness Training**: Phishing recognition, secure password practices
- **MFA Usage Guidance**: Proper authenticator app usage, backup code security
- **Incident Response**: Account compromise procedures, recovery process documentation
